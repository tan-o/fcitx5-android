# 自用修改版

基于 6998502528cd26efb6079556da92003638e4179c，整合上传包的七次修改，并修复实现问题。

## 使用

- 剪贴板：最近 / 已固定两个分栏。点击搜索按钮后，可以输入原文、无声调拼音或首字母；数字和符号键盘可切换。长按查询行可粘贴中文关键词。输入只修改查询，不会打进当前聊天框。拼音匹配使用常用读音，不支持所有多音字组合。
- 语音：在设置中选择语音按钮要切换到的已启用输入法，允许没有 voice 子类型的输入法。它是切换入口，能否直接进入听写取决于目标输入法，三星设备仍需实测。
- 手写：工具栏的手写按钮打开画布。使用 Zinnia 引擎和随 APK 打包的 Tegaki 简体中文模型，全程在本机识别，无需下载模型。支持逐笔识别、候选注音、撤销笔画、清空；没有笔画时撤销键作为退格使用。
- 候选分类：展开候选后可按首字部首 / 总笔画筛选前 500 个候选。正常「全部」分页不限于这 500 项。数据未收录的字仍在全部列表中。筛选结果携带原始下标和输入代次，旧列表不允许选字。

## 手写选型与隐私

根据用户要求，移除 ML Kit、Google 模型下载入口及主应用联网权限，恢复 Zinnia 本地引擎。保留候选注音、撤销、清空、输入代次校验等改进。模型随 APK 打包，首次使用只做本地资源复制。源码和模型许可证在手写资源目录内。

ML Kit 的端侧识别不等于没有遥测。官方披露其诊断和使用分析收集行为，因此此版本不使用它：https://developers.google.com/ml-kit/android-data-disclosure

语音按钮仍然只切换到用户选定的其他输入法；该输入法的数据行为由其自身实现决定。Android SDK、AndroidX、Material 等构建或 UI 依赖不是 Google Play Services。

## 构建和安装

`Build Mods (debug)` 工作流构建 arm64-v8a 的应用和 Rime 插件，并运行单元测试。两者使用同一构建环境里的 debug 签名。下载同一产物中的两份 APK，debug 包名可与官方版本并存。

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug :plugin:rime:assembleDebug -PbuildABI=arm64-v8a
```

配置可从官方版导出后在修改版导入。CI 默认 debug 签名随新 runner 重新生成；本产物适合验证功能，跨构建覆盖安装需要稳定签名。不要卸载现有应用来解决签名冲突，先导出数据。
